# Iris 1.21.11 — Lightweight Shader Pack

This is a small, stable, and lightweight shader pack compatible with Iris for Minecraft 1.21.11. It provides: shadows, simple SSAO, bloom, godrays, basic tone mapping, and a minimal composite pipeline — designed to be reliable and low-cost on performance.

Install (manual):
1. Run the build script to create the ZIP (see build_zip.sh) or zip the `shaders/` folder together with `iris-shaderpack.json`.
2. Place the generated ZIP into your Minecraft shaderpacks folder (e.g., .minecraft/shaderpacks/) or copy the `shaders/` folder into a directory and load it in Iris.

Notes:
- This pack is intentionally simple and written for clarity and stability rather than photorealism.
- If you want the ZIP added as a release asset in the repo, tell me and I’ll create a release and upload the ZIP.
